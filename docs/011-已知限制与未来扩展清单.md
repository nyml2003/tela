# 011-v1 已知限制与未来扩展清单

> 本清单集中记录 v1-MVP **明确不做、后置**的能力，避免散落文档各处。凡新增"不做"项一律归档到本文，并在原文档引用本文。

已经完成且不应继续作为待办的问题，统一见 [016-已解决问题归档](016-已解决问题归档.md)。

## 1. 布局（见 006 §1、§4）

- `Grid` 栅格容器（行列轨道、跨行跨列）：首版砍掉。
- 变高虚拟列表：首版仅定高。
- 自由定位：`FreeCanvas` 自由画布容器 / 局部绝对定位（强制绑定定位上下文）。`VisualConcern.draw_order` 局部绘制序已是 v1 能力（见 [006-布局引擎](006-布局引擎.md) 4），不在本清单。

## 2. 焦点与交互（仍待扩展）

- **虚拟列表内部焦点导航**：离屏 item 不在 UI 树中，方向键导航如何越过/进入离屏 item 的规则仍未定义；不纳入已完成的 M6 基础焦点原语。
- 网格容器焦点逻辑：随 Grid 容器一并后置。
- **无障碍 a11y 语义**：语义角色、WAI-ARIA 等价、辅助技术（AT）接口——B 端/C 端硬性主流实践，当前完全缺失；契约层需预留语义字段（业界参照：WAI-ARIA 语义角色树）。
- **Pointer 高级指针事件**：触摸/多点触控/手写笔、手势识别、滚动惯性——输入事件需预留 Pointer 类别（业界参照：Web Pointer Events 统一鼠标/触控/笔）。
- **命令式焦点调用类型化**：基础 Save/Restore 原语已完成；动态焦点/异步加载后的目标引用仍缺少静态校验和结构化约束。

## 3. 文字与排版（后置）

- 文本方向与布局方向（RTL、阿拉伯等书写系统）：系统约束仅保证中英文 LTR；文本预留方向字段与字体回退栈（业界参照：Unicode Bidirectional Algorithm）。
- 富文本/多 run 样式（同段多样式、省略号、换行规则）：当前文字为单样式块。
- 文本编辑原语粒度（光标/选区/undo 归属基座还是上层）：未定。
- SVG、图片图集或平台图标 provider：`tela-icon-resources` 的 provider 抽象已存在，但当前只有 Material iconfont 实现。SVG/向量路径必须等待 `VectorPath`/`Picture` 这类由 Raster、Canvas、WGPU 全部消费的值语义帧原语；不得用当前会被 Raster/Canvas 跳过的 `CustomDraw` 旁路。

## 4. 性能与能力（后置）

- 流式/无限滚动虚拟列表（无稳定实体 id 场景）：虚拟列表强制 `semantic-id` 的限制，需业务手动管理全量数据。
- 主题令牌/动态尺度（明暗/品牌切换、DPI/缩放）：视觉值为直接值，无令牌间接化。
- 动画/过渡原语：动画驱动完全归宿主，组件层内建动画缺插值原语。
- 图层缓存/重绘边界：每帧全量生成命令，大 UI 存在性能天花板。
- `LayoutBoundary` 显式重布局边界（v1.1 迭代）：当前已有叶子测量缓存与 Dirty 子树 `LayoutBox` 缓存；边界必须复用这套最终约束后的单次测量调度（见 [004-更新策略与状态保持](004-更新策略与状态保持.md) 7）。
- 锚点定位（tooltip 跟随光标、popper 类浮层）：无绝对定位表达力，需后续引入锚点机制。
- 富文本、emoji、非中英文书写系统渲染：超出字形保证范围。

## 5. 平台开发 SDK（见 023、024、028）

- **macOS 仅 Apple Silicon 开发态**：当前只构建 `aarch64-apple-darwin` 的 `Tela.app`；Intel macOS 和 universal binary 需要单独定义 target 与合并策略。
- **原生壳不是生产分发物**：Win32/macOS 当前不提供安装器、应用图标、签名、公证、DMG、自动更新、TLS/认证或开发包信任策略；它们不能由开发 bundle 缓存机制替代。
- **原生文本能力仍是最小子集**：Win32 与 macOS 只提供基本键盘和 ASCII controlled input；IME、死键、剪贴板、拖放和 accessibility tree 必须先由 `tela-ui-foundation` 定义 text channel 契约，再分别由平台 Target 实现。
- **跨机器开发网络由环境负责**：Win32/macOS SDK 启动时只请求调用方传入的完整 `--bundle-index`；不发现 LAN 地址、不打开防火墙、不提供认证，也不持续轮询或热更新远端包。Android USB 开发是单独的本机闭环：固定 `adb reverse` 到 `127.0.0.1:8000`，不扩展为 LAN 发现或无线调试。
- **iPhone 仅 iOS 16+、ARM64、竖屏、iPhone 开发态**：不支持 simulator、iPad、横屏、universal binary 或 Android/iOS 共用 native host；完整 Xcode、Apple Development Team 和真机信任由开发机维护。
- **iPhone 不提供动态交付或生产发布**：iOS 静态链接 `tela-mobile-demo`，不下载 `.tela`、不执行 Wasmtime、没有 bundle/cache fallback；未提供 App icon、App Store archive/export、TestFlight、production signing、自动更新或远程资源加载。
- **iPhone 真机验收尚待执行**：仓库已覆盖 direct mobile session、触控、受控文本、构建/部署命令与依赖门禁，但 Apple Silicon iPhoneOS 链接、签名、安装、Metal surface、safe area、IME 和后台恢复必须在物理设备完成验证。
